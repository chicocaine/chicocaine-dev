# TITLE: Ryoku Linux

I don't think I am ready for setting up and ricing my own Arch Linux. So, I turned to pre-built, opinionated flavors of Arch Linux. I randomly stumbled upon [Ryoku]{.danger} in the wild, thought it was cool, and decided to go for it.

Installing was very straightforward. Download the Ryoku ISO, write it on a FAT32 flash drive using Rufus, turn off secure boot, and boot on the drive. I was impressed with how easy and streamlined installing it was. Partitioning, UEFI, drivers, window managers, themes, file managers, tools, terminal, users; all of it was already ready to go. All I had to do was pick what I wanted and boom, I had a working Linux environment. Then, I setup my secure boot keys using `sbctl`: generate, sign, and append. 

Now, basically, I haven't used a Linux UI before. I also haven't used [Wayland]{.primary} or [Hyprland]{.secondary} before. I only used the terminal of Linux with WSL2. Since I was already familiar with [zsh]{.warning}, [fish]{.success} felt familiar to use. What I had to learn was how to navigate the binds and how tiling worked, which came naturally after a few rounds of using Ryoku Linux.

I then spent a few hours on the settings menu. I do not kid, there are so many settings and themes. I wanted to streamline or make the environment my own, so a few moments were fairly justified. I do have to say, however, that there are just so much to take in, but at the same time, it is very beginner friendly and simple once I got used to it.

[Ryoku]{.danger} is pretty stacked, and it looks good.

I will now try to spend most of my non-gaming, non-heavy [dev]{.tertiary} work, and daily drive on Ryoku Linux,,, see how it feels.

*I must confess that, I only had 80GB for this Ryoku install to test it. And looking back, maybe I do regret it.*

*PS. Ryoku is nice. o7*
